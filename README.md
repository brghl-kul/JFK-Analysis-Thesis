# Network Analysis and Entity Mapping of the Newly Released JFK Assassination Files

This repository contains the source code developed for the Master's thesis:

**Network Analysis and Entity Mapping of the Newly Released JFK Assassination Files**

The project constructs an entity co-occurrence network from the 2025 release of the JFK Records Collection and applies natural language processing (NLP) and network analysis techniques to identify important entities, communities, brokers, and temporal patterns.

---

## Project Overview

The analysis pipeline consists of the following stages:

1. Text acquisition and validation
2. Text preprocessing and cleaning
3. Entity and relationship extraction using spaCy
4. Entity canonicalization and normalization
5. Network construction
6. Community detection (Louvain algorithm)
7. Broker identification (Betweenness Centrality)
8. Timeline analysis
9. Network visualization and statistical analysis
